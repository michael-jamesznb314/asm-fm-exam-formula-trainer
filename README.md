## Using the App

Open the trainer to begin working through its formula prompts. Try to recall each formula before revealing or checking the answer, and use repeated sessions to strengthen memory.

A normal review cycle looks like this:

1. Open the web app.
2. Start a spaced-repetition session.
3. Attempt each formula from memory.
4. Revisit items you miss at shorter intervals.
5. Use the trainer consistently for continued reinforcement.

When running the project locally, reload the browser page after editing HTML content.
